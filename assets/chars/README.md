# キャラクターの絵の入れ方（社長の作業）

このフォルダに **絵のファイルを置くだけ** で、ゲームのキャラの絵がその絵に入れ替わります。

**1枚も置かなくてもゲームはちゃんと動きます。** いまと同じ、プログラムで描いた絵のままです。
置いた分だけ、置いたキャラだけが入れ替わります。1枚だけ置く、途中まで置く、どれでも大丈夫です。

---

## 1. どんなファイルを用意するか

| | 大きさ（おすすめ） | 形式 |
|---|---|---|
| **立ち絵**（カード画面・対戦前の大きい絵） | **横 480 × 縦 680 ピクセル** | PNG（背景が透けているもの） |
| **コマ**（すごろく盤の上を歩く小さい絵） | **横 200 × 縦 280 ピクセル** | PNG（背景が透けているもの） |

- 「ピクセル」は絵の細かさの単位です。上の数字ぴったりでなくても構いません。
  だいたいこの形（縦長）にしておくと、きれいに収まります。
- 「背景が透けている PNG」＝キャラの周りが白や黒で塗りつぶされていない絵のことです。
  白い四角が付いていると、ゲーム画面でもその白い四角ごと出てしまいます。
- 絵が指定より大きい・小さい場合も、こちらで自動的に大きさを合わせます。
  ただし立ち絵は**縦長の枠にぴったり合わせて、はみ出した部分は切り落とし**ます。
  顔が切れないように、**キャラを絵の真ん中**に置いてください。
- コマは**足元が下端**に来るように描いてください（盤の上に立つ位置がそこになります）。

---

## 2. ファイルの名前（この名前でないと入れ替わりません）

キャラは全部で 11 人います。立ち絵は `c`、盤のコマは `t` で始まります。

| キャラ | 立ち絵のファイル名 | コマのファイル名 |
|---|---|---|
| 氷晶の狐（クリスタル） | `c01.png` | `t01.png` |
| 翡翠の鶴（ジェイド） | `c02.png` | `t02.png` |
| 黒曜の狼（オブシディアン） | `c03.png` | `t03.png` |
| 蒼玉の梟（サファイア） | `c04.png` | `t04.png` |
| 真珠の兎（パール） | `c05.png` | `t05.png` |
| 紅玉の竜（ルビー） | `c06.png` | `t06.png` |
| 黄金の獅子（ゴールド） | `c07.png` | `t07.png` |
| 琥珀の熊（アンバー） | `c08.png` | `t08.png` |
| 白銀の狐（シルバー） | `c09.png` | `t09.png` |
| 深紅の竜（スカーレット） | `c10.png` | `t10.png` |
| 琥珀の獅子（アンバーレオ） | `c11.png` | `t11.png` |

- 名前は**小文字**で、数字は必ず2桁（`c1.png` ではなく `c01.png`）です。
- 立ち絵だけ置いてコマを置かない、でも大丈夫です。コマはこれまでの絵のまま出ます。
- PNG のほかに WebP・JPG も使えます（`c01.webp` `c01.jpg`）。
  ただし JPG は背景が透けないので、PNG をおすすめします。

---

## 3. 置き方（3ステップ）

1. 用意した絵を、上の表のとおりの名前に変える
2. このフォルダ（`assets\chars\`）に入れる
3. `build.ps1` を実行する

これだけです。実行すると、画面に

```
キャラ画像: c01, c07, t01  (合計 0.42 MB)
```

のように「どの絵が入ったか」が出ます。ここに出ていない名前は、
ファイル名が違うか、置き場所が違います。

---

## 4. 絵の重さの上限（大事）

**全部の絵を合わせて 10MB まで**にしてください。

- ゲームは2つの形で書き出されます。
  `index.html`（ホームページ用）と `game.html`（Artifact用）です。
- `game.html` は絵を中に埋め込む作りなので、絵が重いと 16MB の上限に引っかかって開けなくなります。
- そこで、**合計が 10MB を超えたら警告を出して、`game.html` には絵を入れません**。
  その場合 `index.html` だけが新しい絵になり、`game.html` はこれまでの絵のままです。
  ゲームが壊れることはありません。

10MB を超えた時は、絵を小さくしてください。
おすすめの大きさ（立ち絵 480×680、コマ 200×280）で作れば、22枚全部置いても
だいたい 3〜6MB に収まります。

---

## 5. うまくいかない時

| 症状 | 見るところ |
|---|---|
| 絵が入れ替わらない | ファイル名が表のとおりか（小文字・2桁の数字・`.png`）。`build.ps1` を実行したか |
| 白い四角が付いて出る | 背景が透けていない PNG です。背景を透明にして書き出し直してください |
| 顔が切れている | 立ち絵は縦長に切り取られます。キャラを絵の中央寄りに描き直してください |
| コマが盤に埋まっている／浮いている | コマの絵は、足元が絵の下端に来るように描いてください |
| `game.html` だけ絵が古い | 合計 10MB を超えて埋め込みを止めています。絵を軽くしてください |
