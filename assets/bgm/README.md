# 音楽（BGM）の入れ方 — 社長の作業

このフォルダに **音のファイルを置くだけ** で、ゲームの音楽がその曲に入れ替わります。

**1曲も置かなくてもゲームはちゃんと鳴ります。** いまはプログラムで作った音楽が流れています。
置いた曲だけが入れ替わり、置いていない場面はこれまでどおりの音楽のままです。
「対戦中だけ本物の曲にする」といった使い方もできます。

---

## 1. ファイルの名前（この名前でないと入れ替わりません）

場面ごとに8曲あります。ぜんぶ置く必要はありません。

| ファイル名 | いつ流れるか | おすすめの雰囲気 |
|---|---|---|
| `lobby.mp3`  | タイトル・ホーム画面 | 明るい。旅立ちの予感 |
| `room.mp3`   | 試合前の待機部屋 | 期待感。これから始まる感じ |
| `game.mp3`   | **対戦中（いちばん長く流れます）** | 転がるようなテンポ。ずっと聴いていられる曲 |
| `tense.mp3`  | 終盤（残り6ターンから） | 焦るが楽しい |
| `boss.mp3`   | 誰かが独占リーチになった時 | 切迫感 |
| `gacha.mp3`  | ガチャ画面 | きらびやか |
| `win.mp3`    | 勝利・結果発表 | ファンファーレ |
| `result.mp3` | 結果画面の余韻 | 明るく締める |

- 名前は**小文字**で、上の表のとおりに。
- `mp3` のほかに `ogg` `m4a` `wav` も使えます（`game.m4a` でも動きます）。

---

## 2. 置き方（3ステップ）

1. 曲のファイルを、上の表のとおりの名前に変える
2. このフォルダ（`assets\bgm\`）に入れる
3. `build.ps1` を実行する

実行すると画面に

```
BGM: game, win を組み込みました（合計 4.2 MB）
```

のように「どの曲が入ったか」が出ます。ここに出ていない名前は、
ファイル名が違うか、置き場所が違います。

---

## 3. ファイルの大きさ（大事）

**全部合わせて 8MB くらいまで**にしてください。

ゲームは2つの形で書き出されます。`index.html`（共有リンク用）と `game.html`（Artifact用）です。
`game.html` は曲を中に埋め込む作りなので、重すぎると開けなくなります。

- 1曲 1〜2分、128kbps の mp3 なら 1曲あたり 1〜2MB です
- 曲は**自動でくり返し再生**されるので、30秒〜1分半のループ素材で十分です

---

## 4. 曲をどこから持ってくるか

**YouTube などの動画から音を抜き出して使うことはできません。**
利用規約に反しますし、その曲に著作権があると、共有リンクは誰でも開けるので
そのまま公開してしまうことになります。

安心して使えるのは、**商用・非商用を問わず使ってよいと明記されたフリー音源**です。
日本語で探せる代表的なところ:

| サイト | 特徴 |
|---|---|
| DOVA-SYNDROME | 曲数が多い。ゲーム向けも豊富。規約は各曲のページに記載 |
| 甘茶の音楽工房 | 明るい曲・かわいい曲が得意 |
| 魔王魂 | ゲーム用の定番。ループ素材あり |

※ **ダウンロードと利用規約への同意は社長ご本人でお願いします。**
　 当方が代わりに同意することはできません（規約に同意するのは使う人だからです）。

ダウンロードしたら、上の表の名前に変えてこのフォルダに入れ、`build.ps1` を実行してください。

---

## 5. うまくいかない時

| 症状 | 見るところ |
|---|---|
| 曲が変わらない | ファイル名が表のとおりか（小文字・`.mp3`）。`build.ps1` を実行したか |
| 一部の場面だけ元の音楽 | その場面のファイルを置いていないだけです。正常な動きです |
| 音が出ない | 画面のどこかを一度タップしてください。ブラウザは最初の操作まで音を鳴らせません |
| `game.html` だけ曲が古い | 合計が大きすぎて埋め込みを止めています。曲を軽くしてください |
