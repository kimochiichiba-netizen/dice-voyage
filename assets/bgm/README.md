# BGM の入れ方（社長の作業）

ここに **4つのファイル**を置くだけで、合成音から本物の曲に切り替わります。
ファイルが無ければ、いまの合成音のまま動きます（壊れません）。

| ファイル名 | いつ流れるか | 曲の雰囲気 |
|---|---|---|
| `lobby.mp3` | ホーム・カード・ガチャの画面 | 明るく、ゆったり。待っていて心地よい曲 |
| `game.mp3`  | 対戦中 | テンポよく、少しワクワクする曲 |
| `tense.mp3` | 残り8ターンから | 緊張感のある、追い込まれる曲 |
| `win.mp3`   | 勝利画面 | 華やかなファンファーレ |

## どこで手に入れるか（商用無料・日本のサイト）

- **DOVA-SYNDROME** https://dova-s.jp/ … 「ゲーム」「かわいい」「ボードゲーム」で検索
- **甘茶の音楽工房** https://amachamusic.chagasi.com/ … 「ほのぼの」「コミカル」
- **魔王魂** https://maou.audio/ … 「ゲーム音楽」

いずれも**利用規約の確認とダウンロードは社長ご本人でお願いします**（規約の同意は
本人が行う必要があるため、私は代わりにダウンロードしません）。

## 置き方
1. 上のサイトで曲を選んでダウンロード
2. ファイル名を `lobby.mp3` `game.mp3` `tense.mp3` `win.mp3` に変える
3. このフォルダ（`assets/bgm/`）に入れる
4. `build.ps1` を実行する

**1曲あたり 3MB 以内**にしてください（4曲で12MB以内）。長い曲は2〜3分にカットするか、
128kbps 程度に落としてください。Artifact版は16MBが上限のためです。
