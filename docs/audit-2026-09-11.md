# コード監査メモ（2026-09-11、クラウドセッション）

`src/` 全体を読んで見つけた不具合と、今回の対応。ローカルの2つのセッション（「ゲットリッチアプリ開発」「ゲットリッチ アプリ再実装」）と
作業が重ならないよう、修正は**局所的な差し替え**に限定し、ブランチ `claude/quality-overseas-audit` に入れた。

## 見つけたが今回は触っていないもの（ローカル側と要相談）

1. **`showCards` などが後勝ちで上書きされ、`5-meta.js` の実装が全部デッドコード**（`showHome/showCards/showDaily/showGacha/showPend/showQuest`）。
   結果として **カードの売却・合成・ロック** が UI から到達不能。`8-dk.js` 側の画面に配線し直すか、`5-meta.js` 側を削るか決める必要あり。
2. `raiseAlarm/alarmTick/sameMono/dropAlarm`（独占の猶予ターン）は誰からも呼ばれていない。使わないなら削除。
3. `#sideHud` を描く分岐があるが要素が無い。`'minigame'` タイル種別は生成されないのに3か所で分岐している。
4. `3c-chars.js / 3d-gems.js / 3f-anime.js / 3g-opm.js` がビルドから外れているのに、設定の「キャラの絵柄」切替 UI が残っている（切り替えても何も起きない）。
5. ランキング・勝利ティッカーは端末内の疑似データ。
6. `tiles[2].amount`（ボーナスマスの金額）、`SV.nick`、`SV.name`、`G.lastTick`、`p.cardLv` は未使用。
7. 画面のスクリーンショット確認では、待機部屋・順番決め・盤面ともに崩れは無し。外部フォント（Google Fonts）と PeerJS はネット遮断環境だと読めないが、フォールバックで動く。
