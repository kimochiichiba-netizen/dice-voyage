# 本家（LINE ゲットリッチ日本版）・海外版との比較メモ（2026-09-11）

## 0. 本家「ワールド」マップの再現（2回目の作業で追加）

社長の指示は「以前の日本版 LINE ゲットリッチが本家。それに近づける」。日本版はサービス終了済みで
公式ヘルプ・攻略wiki（atwiki / AppBank / ファミ通 / help2.line.me）はこの環境から読めなかったため、
記憶にある本家の盤をそのまま `src/3-core.js` の `MAPS[0]`（id: `lgr`）として実装した。

ダイスキングダムの現状（`src/`）と突き合わせ、揃っている点・足りない点を整理した。
この環境からは公式ガイド・wiki 本文（fandom / namu.wiki / netmarble）に直接アクセスできなかったため、
検索結果の要約に基づく。数値は要確認。

## 2. 本家にあって、まだ無いもの（次の候補）

1. **防御カードとしての天使カード**: 本家では攻撃カード（地震・疫病など）を自動で防ぐ。今の天使カードは通行料無料のみ。
2. **強制売却カード**: 相手の建物を1段、所有者に売却させる（60%換金）。地震と差別化するなら「相手が現金を得る代わりに街が弱る」。
3. **チーム戦（2:2）**: 本家の主要モード。オンライン基盤（PeerJS）はあるので座席にチーム属性を足せば可能。
4. **観光地マス**: 本家は「観光地」タイル（買収不可・建物なし・固定通行料）が別枠にある。今はランドマーク数で代替。
5. **サーバ側ランキング**: 現在は端末内の疑似ランキング。
