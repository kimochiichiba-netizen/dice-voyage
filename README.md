# ダイスボヤージュ（DICE VOYAGE）

ゲットリッチ（LINE）と同じ **UI/UX・アニメーション・横画面** を狙って作った
オリジナルのボードゲーム。株式会社気持ち市場。

## 構成
- `src/1-style.html` … タイトル・フォント・CSS
- `src/2-body.html`  … 画面のマークアップ
- `src/3-core.js`    … 盤の幾何・マップ定義・Canvas描画
- `src/4-game.js`    … ゲーム進行・演出・CPU・画面遷移
- `build.ps1`        … 上記4つを結合して `game.html`（Artifact用）と `index.html`（単体版）を出力

## ビルド
```powershell
./build.ps1
```

## 盤の幾何（実機映像の実測値）
| 項目 | 値 | 出所 |
|---|---|---|
| 縦潰し比 k | 0.585 | 実測（教科書的2:1アイソメの0.50より起きた俯角） |
| 盤中心 | (50.5%, 53.5%) | 実測 |
| 横半対角 / 縦半対角 | 39.0% / 40.5% | 実測 |
| マス数 | 32（1辺＝角1＋通常7） | 盤外周の歩数オーバーレイ 1〜12 から確定 |

## 横画面バグを起こさない設計
**1600×900 の固定ステージを1枚置き、viewport に合わせて `scale()` するだけ。**
中身の座標は全て % 固定なので、縦横比が変わってもレイアウト計算が1つも走らない。
縦画面では回転ヒントを出し、回転ロック時は `rotate(±90deg)` で縦のまま遊べる。
